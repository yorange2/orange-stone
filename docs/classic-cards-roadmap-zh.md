## 摘要

怀旧系列仍有 **66 张独立卡牌** 未实现，分为三个梯队：

| 梯队 | 数量 | 说明 | 是否需要新引擎机制 |

| 2 | 30 | 确实未实现，需要新的引擎机制 | 需要 |
| 3 | 16 | 暂缓：随机/发现/对手机制相关 | 需要随机卡池/卡牌生成框架 |

## 机制清单

在实现梯队 2 和 3 之前/期间需要构建的引擎功能。大致按解锁卡牌数量排序：

- [ ] **连击关键词** — 解锁：头部爆裂、绑架者
- [ ] **抉择** — 解锁：塞纳留斯、丛林守护者
- [ ] **攻击/法术目标重定向** — 解锁：误导、崇高牺牲、法术反制
- [ ] **免疫** — 解锁：狂野怒火、角斗士的长弓
- [ ] **临时精神控制（直到回合结束）** — 解锁：暗影狂乱；之后可做永久控制 → 精神控制
- [ ] **变形** — 解锁：工匠大师欧沃斯巴克
- [ ] **费用减免光环与一次性费用效果** — 解锁：巫师学徒、召唤传送门、肯瑞托法师、暗影步、视界术
- [ ] **剧毒** — 解锁：耐心的刺客
- [ ] **带战吼的武器** — 解锁：毁灭之刃
- [ ] **摧毁武器 + AOE** — 解锁：剑刃乱舞
- [ ] **授予亡语 / 授予潜行** — 解锁：丛林之魂、伪装大师
- [ ] **相邻伤害** — 解锁：背叛
- [ ] **延迟到回合开始的消灭** — 解锁：腐蚀术
- [ ] **最低生命值效果** — 解锁：命令怒吼
- [ ] **过载触发** — 解锁：无羁元素
- [ ] **施放法术 → 卡牌入手** — 解锁：游学者周卓、大法师安东尼达斯、奥术智慧宝典
- [ ] **随机卡池框架**（职业/稀有度/类型过滤 + token 卡池）— 解锁：梯队 3 全部
