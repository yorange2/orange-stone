# 引擎机制路线图 — 战吼目标与冻结时序

> 活跃路线图（尚未归档）。两个引擎级机制在 W8~W12 保真债执行期间（PR #97–#101）
> 被刻意搁置：它们都早于 §11 账本、影响整类卡牌而非单卡，因此各自成里程碑并带
> F5 差分覆盖。英文镜像：`engine-mechanics-roadmap.md`。

## 为什么

| 问题 | 现状 | 真实炉石 | 影响 |
| --- | --- | --- | --- |
| 随从战吼目标被丢弃 | `Event::MinionSummoned` 解析战吼时传 `explicit_target = None`（`rules.rs`）——`PlayCard { target }` 只对法术生效 | 指向性战吼（驯兽师、银色保卫者…）命中所选目标；目标离开合法集合则哑火（G9） | 所有指向性随从战吼随机选目标；RL agent 的 `PlayCard { target }` 对它们毫无意义 |
| 冻结从不阻止攻击 | `Event::TurnStarted` 在**回合开始**清除进入回合方实体的 Freeze（`rules.rs`）——对手回合被冻的角色在能攻击前就已解冻 | 被冻结角色下一回合不能攻击；**错过攻击机会后**才解冻（下下回合开始） | 冰霜新星/冰锥术/水元素的冻结形同虚设；`AttackDeclared` 里的冻结检查实际是死代码 |

## 里程碑

### M1 — 随从战吼显式目标

- 把 `PlayCard { target }` 贯穿随从打出路径：`MinionSummoned` 事件（或
  `CardPlayed` 处理器）必须把显式目标传给战吼的 `resolve_effect`。
- 重新校验维持 G9：解析时显式目标已离开合法候选集合则战吼哑火（不回退随机）。
- 审计受影响卡牌（驯兽师——友方野兽、银色保卫者——友方随从、库尔特拉斯
  医师等；法术类指向效果本就正常，PR 里列出完整随从战吼目标清单）并逐张钉
  F5 场景。

**验收**：`m1_*` 差分场景（显式目标战吼命中所选目标；非法目标哑火；RL
`legal_actions` 目标被真正执行）；`cargo test` 全绿；clippy 无警告。

### M2 — 冻结时序

- 把解冻从 `Event::TurnStarted` 移到回合结束收尾：被冻角色带着 Freeze 进入
  其主人的下一回合（攻击被既有 `AttackDeclared` 检查阻止），然后在下下回合
  开始时解冻——官方炉石语义。
- 保留冻结交互契约：寒冰箭对已冻结角色改为造成伤害而非重复冻结；解冻必须在
  下一回合攻击前完成。

**验收**：`m2_*` 差分场景（对手回合被冻的角色下一回合不能攻击、之后解冻；
英雄冻结阻止英雄攻击；寒冰箭双重冻结交互）；`cargo test` 全绿；clippy 无警告。
